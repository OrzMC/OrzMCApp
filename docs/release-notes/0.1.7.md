# OrzMC 0.1.7（build 59）

这次是一次**功能 + 界面版本**：服务器管理页合并成一个列表，卡片交互、刷新与视觉重新收口；
同时带来**服务器资料保存方式**（仅本次安装 / 保留在本机 / iCloud 同步）与 Fabric/Forge 的**模组入口**。

**升级不会动你的游戏文件、服务器档案和钥匙串里的凭据**；已有账号默认仍是「保留在本机」。

---

## 一、服务器管理页合并（macOS「服务器」窗口 + iPhone 首页）

以前自建服务器和远程托管是两个面（macOS 顶部分段控件切换、iPhone 两个 Tab）。
现在合并成**一个列表**：

- 分组固定 **自建 → Exaroton → MCSManager**；没有内容的来源整组不出现
- 页顶只有**一个**「添加服务器」菜单（先选类型：自建服务器 / Exaroton 账号 / MCSManager 面板），
  右边是「全部折叠 / 全部展开」
- 每组标题可单独折叠；点标题或左侧箭头都行
- **整张卡片都能点**（名称、文字、右侧空白都行）进详情
- iPhone 上不再有底部 Tab，启动直接进这个列表

### 刷新

- 卡片上的「刷新」点下去，图标会**原地变成转圈**（不再在标题旁另冒一个）
- iPhone 下拉刷新、macOS **⌘R**（服务器窗口工具栏的刷新按钮）会刷新**全部来源**
- 自建服务器的详情页保留工具栏刷新；MCSManager 控制台页的刷新只重拉历史日志

### 控制台改成"页面"

MCSManager 实例的控制台以前是**弹窗**，现在是**推入的页面**（与主窗口的服务器控制台一致）：
左上角返回按钮回列表，⌘← 也可以。exaroton 的自建控制台不变。

### 视觉

- 去掉"卡片里再套卡片"：账号/面板卡内部的行是平铺行 + 细分隔线
- 三档字阶：分组标题（灰）→ 账号/面板名 → 服务器名
- 版本/玩家/延迟从描边胶囊改成一行纯文本（`·` 分隔），状态徽章仍是唯一的实心胶囊
- 图标按钮：可用状态更亮、禁用变暗，悬停有底色；危险操作图标不再常驻红色

## 二、服务器资料保存方式（新）

每个服务器 / 账号 / 面板都可以**单独**选择保存方式（表单里的「保存方式」）：

| 档位 | 含义 |
|---|---|
| **仅本次安装** | 配置与凭据只属于当前安装；删掉应用即不再保留 |
| **保留在本机** | 保存在本机安全存储中，重新安装应用后仍可恢复；**不同步**到其它设备（默认） |
| **iCloud 同步** | 配置和凭据保存到 iCloud 钥匙串，同一 Apple 账号的设备都能用 |

- 切换档位时会把已存的凭据**迁移**到新位置：先写入并校验、成功后才删旧的；
  失败会**保留原数据**并就地提示，不会把密码弄丢
- iCloud 档位需要设备登录同一 Apple 账号并开启 iCloud 钥匙串；
  **同步不是实时的**（实测约 1–2 分钟传播）
- macOS：设置 → 通用 →「本机资料」→ **清除本机资料…**：删除这台 Mac 上的记录与本机凭据，
  **不会删 iCloud 副本**（那属于你的其它设备）

> 老用户升级后仍是「保留在本机」，不会自动上传或迁移任何记录。

## 三、主窗口

- 服务端卡片的动作顺序改为 **插件/模组 → 控制台 → 启动/重启/停止 → 终止/删除**
- **Fabric / Forge 服务端新增「模组」按钮**（控制台左边）：目前只做**本地清单**——
  列出 `mods/` 里已装的 jar、搜索、重新扫描、在 Finder 中打开。
  **从 Modrinth 搜索/安装/更新模组**会在后续版本接入（见「已知问题」）
- 动作按钮现在能看出"可用 / 不可用"（以前一排全是灰的）
- 目录行右侧的「打开」图标改成文件夹（以前像"打开链接"）

## 升级方式

- 已安装 0.1.6（或更早）的用户：下次启动时通过 Sparkle 提示升级，点「安装并重启」即可
- 手动安装：下载 `OrzMC_0.1.7_59_*.dmg`，拖进「应用程序」
- 系统要求：**macOS 14 或更高**（Intel 与 Apple Silicon 都有原生支持）
- iPhone：同一套页面（Debug/TestFlight 渠道按现有流程安装）

**需要你手动做的事**：没有。已有账号、服务器、游戏文件都不受影响；
想用 iCloud 同步就进对应账号/服务器的表单，把「保存方式」改成 iCloud。

## 已知问题

- **插件/模组还不能搜索安装**：插件面板目前只接 Hangar 渠道，模组面板只列本地 `mods/` 里的 jar；
  Modrinth 与统一渠道（搜索 / 安装 / 更新 / 卸载）是下一个版本的内容
- iCloud 钥匙串的同步是分钟级，不保证点完立刻在另一台设备看到
- MCSManager 的控制台是"实时流优先、3 秒轮询兜底"，面板给不出流时最后一行可能有几秒延迟
