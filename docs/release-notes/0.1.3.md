# OrzMC 0.1.3（build 55）

这是启动器界面与「服务器」能力的一次集中更新。**升级不会动你的游戏文件**
（`~/minecraft` 下的版本、存档、配置、插件都原样保留）。

## 启动器界面

- **详情页重做**：顶部是「启动卡」（选客户端/服务端、玩家名、Java 状态、启动），
  下面按「客户端」「服务器」分组列出实例卡片；每张卡片有独立的状态、进度和动作按钮，
  启动一个实例不会再让其它卡片一起转圈。
- 每张实例卡片可以展开看目录（世界、日志、插件、mods…），未创建的目录会标「尚未创建」。
- 侧边栏：版本行显示「发布日期 · 已装内容（最多两项 + 另 N 项）」，悬停可看全部。
- **设置页整理成 6 页**：通用 / 客户端 / 服务端 / 命令行 / 快捷键 / 关于。
  新增**外观**（跟随系统 / 浅色 / 深色，对所有窗口生效）与 **Java** 面板（本应用安装的运行时）。
- **快捷键可自定义**：启动、返回、切换启动目标、搜索、跳到最新/最旧、全部停止，
  都能在设置里改，并单独说明"与系统级快捷键冲突时谁优先"。
- 再次确认弹窗**统一中文、压到一句话**（删除/停止/重启/终止/清空都只说"会发生什么"）。
- 操作失败时，第一行是中文结论（按错误码），第二行保留原始信息与错误码，方便搜索/上报。

## 「服务器」窗口（新）

主窗口工具栏的 **服务器** 打开一个独立窗口，顶部切换两个面：

- **我的服务器**：填地址/端口即可（不需要任何第三方账号）。
  - 状态卡：在线/离线、版本、`0/20 名玩家`、延迟、MOTD、更新时间（20 秒自动刷新）；
  - **玩家管理**：在线 / 白名单 / 封禁三份名单，每行直接给「踢出 / OP / 封禁 / 移出白名单 / 解封」；
  - **控制台（RCON）**：发命令、看回显，附「常用命令」菜单；
  - **多台服务器**：胶囊菜单切换，可新增/编辑/删除；每台各自保留状态与控制台记录；
  - 设置页有「测试连接」：保存前先查状态，RCON 打开时再跑一条 `list` 验密码，**不落盘**。
    RCON 密码存在**系统钥匙串**。
- **远程托管（exaroton）**：列表改成卡片（摘要卡 + 服务器卡/额度池卡），全中文化；
  刷新与账号入口移到摘要卡上（带文字），不再是工具栏里两个看不出用途的图标。

## Esc 与窗口

- 辅助窗口（设置、控制台、服务器）现在**都能用 Esc 关闭**；主窗口仍然只认 ⌘W / 红点
  （Esc 在那里留给"清空搜索 / 取消输入"）。
- 设置页、控制台窗口的关闭行为与之前一致；详情的控制台页仍用 ⌘← 返回。

## iOS

- 首页变成两个并列入口：**我的服务器**（同上，SLP + RCON）与**远程托管**。
- 我的服务器支持多台档案、玩家管理、控制台与「测试连接」。

## 已知问题

- 自建服务器的玩家名单来自 RCON 的文本回复，个别服务端本地化后会解析不出名字
  （此时显示"未获取"，不影响命令执行）。
- 状态提醒（上线/离线通知）还没做，本次未包含。

## 升级方式

- 已安装 0.1.2 的用户：应用会在下次启动时通过 Sparkle 提示升级，直接点「安装并重启」即可。
- 手动安装：下载 `OrzMC_0.1.3_55_*.dmg`，拖进「应用程序」。
- 系统要求：macOS 14 或更高。
