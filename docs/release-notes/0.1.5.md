# OrzMC 0.1.5（build 57）

这是 **0.1.4 的修复版**，两个都是真机上验收出来的问题，建议直接升级。
**升级不会动你的游戏文件、服务器档案和钥匙串里的 Token / RCON 密码。**

## 修复

- **点「删除」确认框会崩溃**（0.1.4 的严重问题）：
  删除实例 / 删除该版本全部实例目录时的确认框，在中文界面下会直接闪退。
  原因是这条中文文案的参数占位顺序写反了（数字被当成文本处理），只在弹确认框那一下触发；
  现在已改正，并给这类文案加了自动检查（占位符数量/顺序对不上会挡住提交）。
- **远程托管（exaroton）在线后控制台不显示日志**：
  服务器启动完成、状态变成「在线」后，控制台一直停在「等待服务器输出…」。
  原因是服务端每行日志结尾带回车符，被解析逻辑当成"整行重写"丢掉了；
  现在能正常显示，颜色也照旧（INFO 绿 / WARN 黄 / ERROR 红）。

## 与 0.1.4 其余内容相同

0.1.4 的那些改进都包含在内：远程托管错误提示只说一句中文（取消不再弹窗）、
控制台空态回到左上角、内存行排成一行、服务器菜单更清爽、iOS 有了应用图标、
三处控制台统一按 ANSI/`§` 颜色渲染。

## 升级方式

- 已安装 0.1.4（或更早）的用户：应用会在下次启动时通过 Sparkle 提示升级，点「安装并重启」即可。
- 手动安装：下载 `OrzMC_0.1.5_57_*.dmg`，拖进「应用程序」。
- 系统要求：macOS 14 或更高。
- **不需要任何手动处理**：没有配置迁移、没有需要重填的凭据，游戏文件与原存档不受影响。

## 已知问题

- 自建服务器的玩家名单来自 RCON 的文本回复，个别服务端本地化后会解析不出名字
  （此时显示「未获取」，不影响命令执行）。
- 远程托管目前只支持 exaroton 单账号；多供应商（Exaroton + MCSManager）与多实例在计划中。
