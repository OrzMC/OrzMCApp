# OrzMC 0.1.4（build 56）

这一版把 0.1.3 验收反馈里的问题逐条修完了，另外统一了三处控制台的颜色渲染。
**升级不会动你的游戏文件、服务器档案和钥匙串里的 Token / RCON 密码。**

## 远程托管（exaroton）

- **不再弹「远程服务器错误」**：进出详情页、切换额度池时的正常取消不再被当成错误；
  真出错时也只是一句中文（网络不可用 / 账号 Token 已失效 / 服务暂时不可用 HTTP xxx），
  不再把英文原始错误、内部接口名和请求 URL 甩到界面上。
- **控制台颜色**：日志按 ANSI 颜色显示（INFO 绿、WARN 黄、ERROR 红），`§` 颜色码不再显示成
  `§a` 之类；一条消息里含多行日志时也能正确换行（以前会挤成一行）。
- **控制台空态**：没有日志时「等待服务器输出…」回到面板左上角（以前贴在左下角）。
- **内存行**：标签、数值、加减按钮排成一行，小屏不再折成两行。
- 状态徽章（旋转图标）在返回再进入后持续旋转，不会停。

## 我的服务器（自建 SLP / RCON）

- **控制台颜色**：RCON 回显按颜色显示，`§` 颜色码不再裸露；本地回显的命令仍用强调色。
- **服务器切换菜单**：去掉与设置里重复的「编辑…」「删除…」；选中项用「勾 + 加粗 + 着色」
  区分得更明显；点胶囊的空白处也能打开菜单（以前只有文字能点）。

## macOS

- 本地服务端的控制台日志不再把颜色整段剥掉：正常显示 INFO / WARN / ERROR 的颜色。

## iOS

- **有应用图标了**（之前主屏上是一个白框），与 macOS 图标一致。
- 控制台空态、内存行、服务器菜单与桌面端行为一致。

## 升级方式

- 已安装 0.1.3 的用户：应用会在下次启动时通过 Sparkle 提示升级，点「安装并重启」即可。
- 手动安装：下载 `OrzMC_0.1.4_56_*.dmg`，拖进「应用程序」。
- 系统要求：macOS 14 或更高。
- **不需要任何手动处理**：没有配置迁移、没有需要重填的凭据，iOS 端更新后主屏图标自动出现。

## 已知问题

- 自建服务器的玩家名单来自 RCON 的文本回复，个别服务端本地化后会解析不出名字
  （此时显示「未获取」，不影响命令执行）。
- 远程托管目前只支持 exaroton 单账号；多供应商（Exaroton + MCSManager）与多实例在计划中。
