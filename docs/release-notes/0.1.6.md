# OrzMC 0.1.6（build 58）

这次是一次**功能版**：远程托管里新增了对 **MCSManager 自建面板**的支持，
并且 exaroton 一侧的错误提示、控制台体验也有改进。
**升级不会动你的游戏文件、服务器档案和钥匙串里的凭据。**

---

## 新增：支持 MCSManager 自建面板（远程托管）

以前「远程托管」只支持 exaroton 官方托管。现在同一个页面里可以再加你自己的
**MCSManager 面板**（自建/云服务器上的那种），按供应商分组显示，互不干扰。

### 怎么用

1. 远程托管页 → **MCSManager** 分组 → 「添加面板」
2. 填**面板地址**（例如 `panel.example.com`，不写 `https://` 也行）+ **API Key**
3. 点「测试连接」先试一次（不会保存），成功会显示「已连接：管理员（N 台实例）」

面板侧有两个前提，缺了会连不上：

- 面板版本 **10.x**（更老的版本接口不同）
- 面板设置里**打开「API Key」功能**；Key 在「用户信息 → API Key」里生成

> 面板没开这个功能时，你会看到面板原话「API Key功能已关闭」——不是网络问题。

### 普通用户和管理员都能用

以前这块有个坑：**普通用户的 API Key 一律看不到实例**（因为普通 key 无权调管理端点）。
现在会自动识别账号角色：

| 你的账号 | 能看到什么 |
|---|---|
| **管理员**（permission 10） | 面板上**全部节点**的所有实例 |
| **普通用户**（permission 1） | **只看到分配给你的**实例 |

两种都在真机上验证过（iPhone + macOS，管理员 key 与普通用户 key 各一组）。

### 面板可以改，也可以删

面板卡片右侧 `⋯` 菜单：

- **编辑面板**：改名称 / 地址 / API Key —— **Key 留空 = 不修改**（只改地址时不用重新粘贴 Key）
- **移除面板**：只删本机配置与钥匙串里的 Key，**不影响面板本身**

### 实例动作：启动 / 停止 / 重启

实例行右侧 `⋯` 菜单里有启动、停止、重启。行为上做了几件事：

- 点完**立刻**显示「启动中 / 停止中 / 重启中」，不用等下一次刷新（面板返回很快，但状态变化要几秒）
- 状态没稳定时（过渡态）按钮是灰的，避免连点
- 失败时会在实例下面显示**面板自己的原话**（例如「参数不正确或非法访问实例」「节点未连接」），
  而不是笼统的"出错了"

### 控制台：点实例行就能进

点实例的名称/地址即打开控制台：

- 显示面板的**最近一段**终端输出（每 3 秒刷新一次）
- 颜色照旧（INFO 绿 / WARN 黄 / ERROR 红），与 exaroton、本地服务器**共用同一套渲染**
- 底部输入框可以直接发命令：`/` 开头是 Minecraft 命令（`/list`），不带 `/` 是控制台命令（`stop`）
- 只有在「在线」状态才能发；发送失败会把内容还给输入框，不会默默吞掉

## 改进：exaroton 侧

- **错误信息更准**：远程托管的 403 / 5xx 会转述服务端原话；
  服务端返回了我们看不懂的格式时，会明说是「这个版本还不认识，请告诉我们」，不再笼统报错
- **请求超时收紧**：MCSManager 面板请求 20 秒超时（之前卡住时界面会一直转圈）

## 升级方式

- 已安装 0.1.5（或更早）的用户：应用下次启动时通过 Sparkle 提示升级，点「安装并重启」即可
- 手动安装：下载 `OrzMC_0.1.6_58_*.dmg`，拖进「应用程序」
- 系统要求：**macOS 14 或更高**（Intel 与 Apple Silicon 都有原生支持）

**需要你手动做的事**：没有。已有的 exaroton 账号、本地服务器、游戏文件都不受影响；
想用 MCSManager 就是多一步「添加面板」。

## 已知问题

- MCSManager 的控制台是**每 3 秒轮询**面板的日志尾部（不像 exaroton 那样有实时推送），
  所以最后一行可能有最多 3 秒延迟；面板上的「强杀（kill）」动作还没做（后续版本补）
- 面板若挂在 Cloudflare Tunnel 后面，**首次**请求可能要十几秒（我们给到 20 秒）；
  期间会显示「加载中…」，不是卡死
